## ✨ How I Build

**I start with a problem, not a technology.**

I like asking "What if this worked differently?" and seeing how far that question can go.

My approach combines design thinking, structural analysis, experimentation, and hands-on testing.

AI helps bridge the gap between design and implementation, allowing me to turn ideas into working software, evaluate them, and keep improving.

I don't build apps because I have a grand plan.

I build them because I keep finding things I want to make better.
